  - Terminal 줄에 수준(info·warn·error) 색 표시, 새 출력이 보이도록 자동 스크롤.
- 결정(위임 범위): 주석 변형은 `# @if <flag> <op> <literal>` / `# @else` / `# @end` 지시문(중첩 없음). 함수 추가 알림은 Terminal 한 줄, 커서 이동 없음. 시나리오 순수성은 테스트(함수 탐색 + JSON 왕복)로 확인. 탭이 모두 사라지면 시작 파일 하나를 연 화면으로.
