# P04 — 시나리오 *Incident 02:14*

**상태:** Planned · [인덱스](00_index.md)

## 목표

처음부터 엔딩까지 플레이 가능한 첫 시나리오를 완성한다 (ideation Week 3).

## 선행 조건

- P03 산출물: 시나리오 계약, 엔진, 저장
- [DB-01](../decision_briefs/01_mvp_dynamic_content_scope.md) 해결 (분기 연출에 쓸 수 있는 수단이 정해져야 함)

## 범위

- [SoT §5.4](../SOT.md#54-mvp-스테이지-구성)의 스테이지 5개 파일과 초기 파일(`main.py`, 설정 파일)
- 사건 함수 10~15개: 주석(상황·선택지), 업무용으로 일관된 더미 코드, 지정 변수
- 분기 그래프: 공통 합류 지점을 둔 상태 머신, 일반 엔딩 2개
- 선택별 Terminal 로그, 잘못된 입력 메시지 문구
- 시나리오 검증 테스트 ([아키텍처 §8](../architecture/00_overview.md#8-테스트-전략)): 전이 대상 존재, 모든 사건 도달 가능, 각 엔딩 도달 경로 존재, 템플릿 주석의 선택지 번호와 `editableFields` 허용값 일치
- 분기 그래프 문서: `docs/scenario/incident-0214.md` (사건 목록과 전이표)

## 완료 기준

- 시나리오 검증 테스트 통과
- 두 엔딩 각각 수동 완주
- 처음 플레이하는 사람 기준 10~20분 (AC-10) — 최소 1회 측정
- 프로그래밍을 모르는 사람이 주석만 보고 진행 방법을 이해 (R-07) — 최소 1회 관찰

## 병행 가능 작업 / 제외

- 병행 가능: P05의 단축키·편집 UX 개선
- 제외: 히든 엔딩, 추가 시나리오, DB-01에서 제외된 동적 연출
