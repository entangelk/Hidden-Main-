# P04 — 시나리오 *Incident 02:14*

**상태:** Complete — 사람이 해야 하는 두 기준(AC-10 플레이 시간, R-07 비개발자 관찰)은 P05 점검표로 이월 (검증: `docs/verifications/2026-10-22/p04_scenario*.md`) · [인덱스](00_index.md)

## 목표

처음부터 엔딩까지 플레이 가능한 첫 시나리오를 완성한다 (ideation Week 3).

## 선행 조건

- P03 산출물: 시나리오 계약, 엔진, 저장
- 분기 연출 수단은 [DB-01](../decision_briefs/01_mvp_dynamic_content_scope.md)(B)로 정해짐: 새 사건 주석·로그 변형, 전이, 엔딩

## 범위

- [SoT §5.4](../SOT.md#54-mvp-스테이지-구성)의 스테이지 5개 파일과 초기 파일(`main.py`, 설정 파일)
- 사건 함수 10~15개: 주석(상황·선택지), 업무용으로 일관된 더미 코드, 지정 변수
- 분기 그래프: 공통 합류 지점을 둔 상태 머신, 일반 엔딩 2개
- 선택별 Terminal 로그, 잘못된 입력 메시지 문구
- 시나리오 검증 테스트 ([아키텍처 §8](../architecture/00_overview.md#8-테스트-전략)): 전이 대상 존재, 모든 사건 도달 가능, 각 엔딩 도달 경로 존재, 템플릿 주석의 선택지 번호와 `editableFields` 허용값 일치, 각 사건의 마지막 전이는 빈 조건, 각 필드의 `필드명 = 리터럴` 줄이 사건 블록 안에 정확히 하나, `>=`/`<=`는 숫자 값에만, 템플릿에 탭·삼중 따옴표·사건 함수 안 중첩 `def` 없음, 기본값 문자열에 `#`·`\` 없음, 템플릿 안 사건 함수 순서 = `Stage.sceneIds` 순서, 도달 가능한 모든 경로를 렌더해 주석 변형 지시문 오류 없음·화면에 `# @if`/`# @else`/`# @end` 줄이 남지 않음(함수 밖 지시문 금지), 전이가 이미 도달한 사건으로 되돌아가지 않음
- 분기 그래프 문서: `docs/scenario/incident-0214.md` (사건 목록과 전이표)
